## Racer Data

Every racer stores:
- **Name** — display name
- **Portrait** — 2D portrait image for menus
- **Icon/Symbol** — small icon for HUD position display
- **Model** — the racer's character model (in-cockpit visible)
- **Base Pod Stats** — 15 attributes (see [pod-stats.md](pod-stats.md))
- **Physical Handling Factors** — pod width, cable length, binder length
- **Active Ability** — unique elemental ability on cooldown
- **Records** — map of best race time and best lap time per track
