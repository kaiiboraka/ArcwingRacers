# Session Start Protocol — ArcwingRacers

## ⚡ MANDATORY: Read This Every Session

At the start of **every** working session on this project, before doing anything else:

1. Read `docs/agent-context/context-map.md` — project identity, vocabulary, doc status, and routing.
2. Read `docs/agent-context/agent-rules.md` — all behavioral rules for docs and code.
3. Read `docs/agent-context/follow-up-tasks.md` — deferred tasks and what's pending.
4. Skim `docs/unfiled-ideas.md` — check for anything that needs filing.

Only after completing steps 1–4 should you begin responding to any task or question. Exception: follow-up-tasks do not need to be totally COMPLETED right away, but they should be brought up as an option for what to do next.

This protocol exists because this project spans multiple sessions and multiple collaborators. The docs here are your working memory. Don't skip them.
